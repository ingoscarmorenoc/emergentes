Blockchain: una cadena que delata cualquier cambio

Cada bloque guarda datos, el hash del bloque anterior y un número llamado nonce. El hash es una huella digital SHA-256: si cambia una sola letra, cambia toda la huella. Minar es probar nonces hasta que el hash empiece con cierta cantidad de ceros.

0hashes calculados
0/4bloques válidos

Qué está pasando

El campo “Hash anterior” de cada bloque se copia del bloque de la izquierda. Por eso, si alteras los datos de un bloque, su hash cambia y todos los bloques siguientes quedan inválidos. Para falsificar la historia habría que volver a minar toda la cadena más rápido que el resto de la red: eso es la prueba de trabajo.

Sube la dificultad a 4 y compara cuántos intentos necesita el minado. Cada cero adicional multiplica por 16 el trabajo promedio.

Para tus proyectos: los contratos inteligentes son programas que viven en una blockchain y se ejecutan solos cuando se cumplen condiciones. Se escriben, por ejemplo, en Solidity para Ethereum.

Inteligencia artificial: aprender de los datos

Un perceptrón es la neurona artificial más simple: multiplica las entradas por pesos, suma y decide. Entrenar es ajustar esos pesos cada vez que se equivoca. Haz clic en el lienzo para crear puntos de dos clases y entrénalo.

w = [0, 0, 0]pesos

Cómo leer el lienzo

El eje horizontal puede representar horas de práctica y el vertical, entregas a tiempo. La línea es la frontera de decisión que aprende el modelo: el color de fondo muestra cómo clasificaría cualquier punto nuevo.

Carga los datos XOR y entrena. Ninguna línea recta logra separar esas clases: por eso existen las redes neuronales con varias capas, la base del aprendizaje profundo.

Para tus proyectos: en Python, este mismo modelo existe como sklearn.linear_model.Perceptron.
